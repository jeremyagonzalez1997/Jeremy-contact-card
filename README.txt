Jeremy Gonzalez — Professional NFC Contact Site

This build is a static, mobile-first contact and sales landing page for Jeremy Gonzalez at Honda of Staten Island.

Included:
- Save My Contact vCard
- Tap-to-call, text, and work email
- Facebook and TikTok links
- New Honda inventory link
- Pre-Owned inventory link
- Google Review link
- Honda of Staten Island map and device-aware directions
- Live dealership sales-hours display
- Jeremy profile photo

Scheduling / appointment functionality has been completely removed from this build. There is no appointment form, calendar integration, Google Apps Script connection, scheduler configuration, or booking backend in the public site.

Deploy the contents of this folder as a normal static site.
